samajh paunga ki photo kis dish ke liye hai.

Windows me naam badalna: file pe **right click → Rename**.

## Photo ki requirements

- **`.jpg` ya `.png`** — `.webp` / `.heic` pehle `.jpg` me convert kar dunga
- **Chahe garmi ho** — main chhota kar dunga. Site har photo ko load karti hai
- **Bhaari photo mat bhejo** (10 MB+ se bachein)

## Sirf 2-3 photo bhi de sakte ho

Baaqi ki jagah main placeholder laga dunga. Jaise sirf biryani ki photo di to
biryani asli dikhegi, baaki placeholder — galat photo se bekaar.

## Credit ka kya hoga

Aapki apni photo = koi credit nahi chahiye, koi licence nahi chahiye.
Main credits page se hata dunga.

Sirf tab credit likhunga jab photo kisi aur ka ho — aap batana ki kiska hai.

## Ye folder kaise khologe

Windows me: khule folder me **address bar** par click karo, usme likho:

```
drop-photos
```

phir Enter dabao. Ya `C:\Users\LENOVO\Desktop\foodhut\drop-photos` likh do.
